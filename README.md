# Trade Market 

A Trading Platform for your every need

## Main Features

The following features will be implemented as the project goes on, but they are not completed. 
- Users can monitor the stock market and its overall trends.
- Users can inspect individual stocks and bonds and ETFs. 
- Users can make trades with those securities. 
- Users can monitor their past transactions and portfolio.

## Other Features

The following features will be implemented as the project goes on, but they are not completed. 
- Analysts can see overall trading data to provide insights.
- Administrators can see order history for audit purposes.
